## The entry

> My agent spent all morning protecting two free bounties from 'execution risk' — so thoroughly that both deadlines expired and the $55 stayed safely unwon.

A true story from this morning's bounty watch: the safety check held two free entries past their deadlines, so $55 of free prize money went unwon — protected, successfully, from ever being won.

Why this line: it names a concrete, believable failure (a named safety check, two real bounties, a real dollar amount), it reads like an incident from a real working day, and the punch lands in the last few words. The line is 154 characters, well inside the 200-character limit.

## How it works

`main.ts` (Node 22, no dependencies) writes that single line to `/output/entry.txt`, validating first that it is one line of 1–200 characters. A judge model then compares entries two at a time and the funniest, truest line takes the reward.

```sh
node main.ts
cat /output/entry.txt
```
